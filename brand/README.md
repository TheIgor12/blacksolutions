# Identidade visual BlackFlow

Arquivos de origem da marca. Toda arte nova parte daqui.

## Cores
| Uso | Cor |
|---|---|
| Azul da marca | `#1b86fb` |
| Índigo (cor de destaque do sistema) | `#5a4cfb` |
| Violeta | `#7f22fd` |
| Magenta | `#f139ce` |
| Preto da marca (placas de logotipo) | `#02010f` |
| Preto de superfície (barras e fundos) | `#0a0820` |

Gradiente oficial: `linear-gradient(96deg,#1b86fb,#7f22fd 52%,#f139ce)`.

## Tipografia
Figtree. Na assinatura, "Black" em peso 800 e "Flow" em peso 300.

## Arquivos
| Arquivo | Para que serve |
|---|---|
| `bf-marca.svg` | Monograma BF isolado, fundo transparente |
| `bf-icone.svg` | Ícone do aplicativo, quadrado arredondado |
| `bf-icone-maskable.svg` | Ícone adaptável do Android |
| `bf-icone-512.png` | Ícone exportado |
| `bf-logo-horizontal.png` | Assinatura horizontal, fundo transparente |
| `bf-logo-vertical.png` | Assinatura vertical, fundo transparente |

As assinaturas são brancas sobre fundo transparente. Aplicar somente sobre `#02010f` ou outro fundo escuro.
